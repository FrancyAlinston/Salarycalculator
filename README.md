# Salary Calculator 💰

A clean, modern Android application for calculating net salary based on gross income and tax deductions. Built with Kotlin and Jetpack Compose.

## Features
- **Calculate Net Salary:** Instantly computes your take-home pay based on your gross salary and tax rate.
- **Modern UI:** Built using Android's latest UI toolkit, Jetpack Compose, for a smooth and responsive experience.
- **Easy to Use:** Simple, intuitive fields for quick calculations.

## Installation
1. Go to the **Releases** section on this GitHub page.
2. Download the latest `app-debug.apk` file.
3. Transfer the APK to your Android device.
4. Tap the APK file to install (make sure you have allowed "Install from Unknown Sources" in your device settings).

## Development
To build the project locally:
```bash
./gradlew assembleDebug
```
The APK will be generated at `app/build/outputs/apk/debug/app-debug.apk`.
